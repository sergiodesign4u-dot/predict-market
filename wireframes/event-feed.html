zone: bottom nav (mobile only, swaps to top nav at 640px)
annotations: zone to job / finding
  1. Top bar / utility cluster (no sign-in to browse) -> EJ2 first impression: the product is legible before any registration. Wallet and How It Works stay utilities, not a primary slot (G4).
  2. Top nav 4 slots, badge in the bar (desktop) -> Desktop layer D-desktop-1 and D-desktop-2: same 4 destinations move to a top bar at >=640px; the unread badge stays permanently visible.
  3. Category + sort bar -> FJ1: find the event while it is still relevant. Categories Politics, Crypto, Culture, General.
  4. Context snippet on each card -> FJ2 differentiator: context before the tap, "why this price", not just a percentage. Snippet hard-lock: present at every breakpoint, never dropped to add a column (D-desktop-3).
  5. Probability % as a real number -> Addition A (grey-box data): the number carries meaning, so it is a labeled sample value, not an empty box.
  6. Card -> Open event detail -> MJ entry: the first tap of the main flow (Event Feed -> Event Detail).
  7. Notifications badge -> FJ1 return trigger; the unread count drives hot/warm return (aarrr D1-D3). Appears once per breakpoint: bottom nav on mobile, top nav on desktop, never both at once.
  8. Sample-content honesty -> Addition B: every event is illustrative sample data, marked as such, never a real market or a verified fact.

documented variant (not built here)

Return-visit denser layout: on return visits the feed is denser (context trimmed, more cards above the fold) per IA/sitemap.md Event Feed. It is a documented variant, not a separate page in this step. First-visit vs return-visit naming stays deferred (P3-4 in IA/flows.md). The page above is the first-visit, story-driven layout.

responsive behavior (verify by resizing)

Mobile base: 1-column feed, bottom nav. At >=640px: top nav replaces bottom nav, 2-column feed. At >=960px: 3-column feed. At >=1280px: 4-column feed. Minimum card width around 280px caps the column count; the context snippet is never removed to add a column.
