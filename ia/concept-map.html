Concept Map

The concept layer of the IA: screens grouped by the user's intent, the navigation model that reaches them, and the trace matrix that proves every job and every screen is covered.

ⓘ Reading order: the concept sitemap shows what screens exist and why (grouped by intent). States (empty, error, loading) live in the flows layer; page contents live in the detailed wireframe layer, not here.
01 / Concept sitemap

Concept sitemap by intent

Concept map - screens grouped by user intent. States live in the flows; page contents live in the detailed layer. Each node is a screen carrying its job tag. Clusters A → B → C → D mirror the CJM To-Be journey: Find → Stake → Follow / settle → Share. Cluster E is the trust anchor that runs alongside; the ORPHAN cluster holds screens that no confirmed job maps to (not built).

02 / Navigation model

Navigation model

Navigation is derived from the job sequence, not a competitor tab bar. Each global entry maps to one intent cluster, so the nav bar and the concept sitemap tell the same story. Mobile is the source of truth (bottom nav, 4 slots plus a header bell); desktop is the same set re-expressed as a lean header.

Global navigation - each entry is an intent cluster

EntryOpensIntent clusterJobs served
Events (slot 1) Event Feed A · Find an event FJ1, FJ2, MJ
My Bets (slot 2) Active Bets (Active + History) C · Follow and settle EJ1, MJ, FJ5, EJ3
Favorites (slot 3) Favorites view (a filter over the feed) A · Find an event (return / watchlist) FJ1
Portfolio (slot 4) My Profile + portfolio summary (account hub) D + E · Prove / trust SJ1, SJ2, FJ4
Notifications (header bell) Notifications list (both breakpoints) C · Follow and settle (return trigger) FJ1, FJ5

Tap count to the primary job (Alex, News Junkie)

ⓘ MJ, real stake on an event, within the 3-tap rule. Events (Level 0) → tap an event card → Event Detail (1 tap). The bet panel is already on Event Detail, so building the bet adds no navigation; Confirm in the panel fires the activation gate at 2 taps total. Bet intent is reachable in 1 tap, the gate fires at 2. Confirmed in sitemap.md Depth Map (better than the old 3-tap standalone Bet Screen path).

Global / contextual / deep split

Global
Level 0. One tap from anywhere in the app.
Events - Event Feed
My Bets - Active Bets
Favorites - Favorites view
Portfolio - account hub
Notifications - header bell + badge
Deep
Level 1. One tap below a Level 0 screen.
Category page - from the second-level nav
Event Detail - tap any event card
Notifications list - header bell
Wallet / Deposit - avatar menu, Portfolio hub
How It Works - avatar menu + footer
Contextual / invoked
Reached only inside a flow. Never a nav slot.
Bet panel - inline on Event Detail
Sign In / Register - dialog at the gate
Deposit - dialog chained after Sign In
Win / Loss Screen - invoked on resolution
Public Profile - external shared-card link only
