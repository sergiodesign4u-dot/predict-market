# Brand toolkit plate — exploration

A single "one plate, reviewable at a glance" brand board for **Predict Market**
(mobile-first Web3 prediction market). This is a fresh brand-mood exploration,
independent of the Signal / Pulse / Harbor UI directions in `concept/`.

## The trust / emotion brief (why the mood is what it is)

- **User:** Alex, a News Junkie, 20–40. Follows events, wants "real skin in the
  game", but is NOT a trader.
- **Core tension:** the thrill of having a stake vs. the fear "this looks like
  crypto, so it's a scam". Platform betrayal is the #1 churn driver.
- **What they need to feel:** smart & validated ("I was right"), safe (money held
  honestly, clear rules), never lost, calm confidence — not casino adrenaline.
- **How trust reads visually:** legibility + calm (opacity = distrust); solidity /
  steadiness (not shine); transparency taken literally (shown, not hidden); human
  warmth via real event photography over cold crypto; ONE confident accent = a
  brand with a point of view, not a rainbow casino.
- **Essence:** "Calm conviction — a spectator's clear-eyed read on the real world,
  where a single decisive signal cuts the noise, and everything is shown."
- **Mood words:** clear-eyed · grounded · charged.

## The plate layout (both variants share it)

One landscape board (3:2), flat / top-down, organized into labeled zones:
Identity (wordmark + a single upward pulse/tick mark) · Palette (swatch row with
hex labels) · Typography (grotesque specimen, "YES / NO") · Icon language (3×3
thin-line grid) · UI direction (two phone mockups of the event feed with an odds
bar) · Social tiles (two square posts).

## How to use

1. Open `prompt-A-daylight-ledger.md` or `prompt-B-grounded-vault.md`.
2. Paste the prompt into ChatGPT (image generation). Ask for **landscape 3:2**.
3. Save the result into `images/` (e.g. `A-daylight-01.png`, `B-vault-01.png`).

Note: any text-to-image model garbles fine text / hex labels — the plate conveys
**mood and composition**, not a pixel-accurate spec. Exact tokens live in code.

## Variants

- **A — Daylight Ledger:** light, editorial, ink-on-paper. Transparency as literal
  daylight; open-record trust. One cobalt signal.
- **B — Grounded Vault (v2, expanded):** dark graphite + matte antique brass. Solid,
  premium, verified; trust through weight and craft. The chosen direction so far.
  v2 swaps the redundant second phone for a **desktop web mockup + one phone** and adds
  richer objects (secondary lockups, logo-construction grid, UI-components sheet,
  real-world applications) — inspired by the NEO MIRAI board's variety and a
  Polymarket-style desktop, without copying either.
- **C — Analog Deck (retro-futuristic):** 1970s space-program optimism + analog control
  deck. Warm charcoal, amber-orange, teal, brushed chrome. Tasteful analog-futurism
  (mission-control / NASA-almanac), deliberately not neon-casino synthwave.

Note: B and C are dense multi-zone boards — generate at **16:9**.
