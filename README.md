# Prediction Market Platform

A mobile-first web platform for prediction markets. Users bet YES/NO on real-world events using crypto (stablecoins). Outcomes are resolved against reality — bet right, earn; bet wrong, lose.

## Key Goals
- Transparent, accessible UX for users new to prediction markets
- Mobile-first, Web3-native
- Trust as the core product value

## Market Types
- Binary YES/NO markets
- Multi-outcome markets

## Status
MVP in development — ~3 months
