Tokens

Two levels. Primitive is a raw value with no opinion: a graphite step, a brass step, a gap, a radius, a type size. Semantic is a role: why this colour is in this place. A component reads colour only through a role, and reads geometry straight from the primitive, because a radius has nothing for a theme to override and a colour does.

This page links the real components/tokens.css, so every swatch below is painted by the file itself. Names, values and notes are generated from it by ui-kit/_gen_tokens_page.py; the reading behind the roles is in ui-kit/docs/tokens-audit.md.
