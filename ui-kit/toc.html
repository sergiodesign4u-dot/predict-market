components/toc.css
/* components/toc.css
   Component: toc. Classes: .toc, .toc-d, .toc-head, .toc-link, .toc-list, .toc-n.

   The page's own contents: a rail of anchors into the document beside it.

   WHY IT IS A COMPONENT AND NOT A VARIANT OF catnav. The two rails have the same
   geometry and opposite jobs. A category rail navigates BETWEEN pages and its
   rows are buttons; a contents rail navigates INSIDE one page and its rows must
   be anchors, because a contents built out of buttons is not crawlable and this
   product's own SEO layer (ia/docs/pages/seo.md section 6) requires every H2
   anchor to be a real link. Putting the sections of a legal document into a
   component called catnav would also have been the third naming lie on one
   screen, and ui-kit/docs/backlog.md item S6 already counts the first three.

   THE RAIL SLOT IS A CONTRACT, and this file honours it: a rail declares its own
   flex-basis and its own sticky, exactly as .subcat does in catnav.css, and the
   shell (components/patterns/browse-shell.css) declares only that there are two
   columns. So a third rail can arrive later without either file learning about
   it.

   MOBILE IS A DISCLOSURE, AND THE REASON IS MEASURED. ia/docs/blocks.md block B5
   says the contents is collapsed above the body on mobile. Built open first, to
   check whether the bank was being cautious: at 360 the fourteen rows pushed the
   H1 of the document entirely below the fold, so the first screen of a legal page
   was a list of links to a title the reader had not seen. The bank was right.
   Desktop does not need the control, so the summary goes and the content is
   forced open through ::details-content, which is the only way an author can
   override the closed state a UA owns.

   Reads: --bg-control-hover, --bg-pressed, --border-hairline, --color-action, --text-brass, --text-muted, --text-primary
     --text-brass, --text-muted, --text-primary
   Stand:  ui-kit/toc.html
   Stands on: 1 ui-visual screens (terms.html)
   Colour goes through a role, geometry straight from a primitive. No em dash. */

/* THE RAIL, at the width the shell hands it. Same breakpoint and the same 214px
   as the category rail, because the slot is one slot: a document that put its
   contents at a different width would make the two rails disagree about what a
   rail is. The sticky top clears the app header and the condensed strip, which
   is the number catnav.css already solved for the same chrome. */

  .toc{flex:0 0 214px;position:sticky;top:120px;align-self:flex-start}
  .toc-head{display:none}
