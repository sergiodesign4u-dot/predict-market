What a molecule is, and how the level was decided

A level is one plus the highest level of what a component contains, and that arithmetic has a blind spot: a component built entirely out of its own class names reads as containing nothing and answers 1. So each level below is declared with a reason, in docs/inventory.md, and this page shows the declaration next to the thing it is about. HOLDS names what is inside, poinwise, even where the arithmetic could not see it.

Two of the fourteen were filed as atoms and are not. The trust strip holds three items, each a mark and a line; the market block holds a question, a rule and a source. Both are made of their own names, which is exactly the case the declaration exists for.

Every specimen stands inside body.app-case, and it has to. A large part of this system is scoped to that class, and the consolidation found the cost: 28 amount chips sit in a dialog outside it and would render as raw User Agent buttons if that dialog opened. It is the dependency the system requires and never declares.
