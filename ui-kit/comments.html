The rule

A container keeps the well and gives up the control. Every rule this file lost was a control; every rule it kept is a place: the list, the row, the indent, the gap under the prompt, the well around the sorter.

Sameness is measured, not felt. The sorter left because two files held the same declaration block byte for byte, and nobody had put the two readings side by side.

The anti-rule

Never keep a rule for a tree that cannot see it. Two of them sat here harmlessly for as long as something else outranked them, and arrived on 90 chips the day it stopped.

Never let a file own a control by category. The tab file held the comment sorter because "that file owns every switcher", and every one of its seven rules was scoped to this component's container.

Never leave a written decision behind the product. This file still explains why its actions are not 44, and they are 44.
