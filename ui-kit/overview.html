The reasoning

Why the system is shaped like this, what it was read out of, and what each part reaches. Rendered from ui-kit/docs/ by ui-kit/_gen_docs.py; the markdown stays the source.

Every file, every page

One component is one css file, one page here and one line in the registry. Missing any of the three means the component does not exist yet. The last group is the second level of the system: a pattern is an arrangement that repeated on three or more screens, and it has a file and a page but no level, no specimen and no states. Its card frames the pattern itself, because that page is the only place a pattern exists outside the product.
