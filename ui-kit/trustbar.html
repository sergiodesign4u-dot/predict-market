States

Hover and focus are not faked here with a stand class. The frames above are live, so hover them; what follows is what the file says will move.

This file declares no state rule: the component looks the same at rest, on hover and on focus.

Colour comes in only through these. Change one on the token page and it changes here and on every screen at once.
